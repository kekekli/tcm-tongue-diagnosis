**前端期望的格式**:
```json
{
  "tongueBody": {
    "color": "舌质颜色",

  },
  "constitution": {
    "primary": "体质类型"
  },
  "advice": "健康建议",
  "products": [...]
}
```

**修复**: 重构后端API以返回正确的数据格式

1. 接收用户上传的舌诊图片（base64格式）
