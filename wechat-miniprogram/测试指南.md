## 🔧 常见问题解决

### ❌ API连接失败
```
解决方案：
1. 确认后端服务运行：curl http://localhost:3002/api/health
2. 检查网络设置中的域名校验是否关闭
3. 尝试使用内网IP替换localhost
```

### ❌ 图片上传失败
```
解决方案：
1. 检查开发者工具中的文件权限
2. 确认选择的图片格式为jpg/png
3. 检查图片大小是否超过10MB限制
```

### ❌ 分析超时
```
解决方案：
1. 检查后端日志是否有错误
2. 确认API接口返回格式正确
3. 增加网络请求超时时间
```
