# 🔧 微信小程序调试实战指南

## 🚀 准备工作

### 1. 确保后端服务运行
```bash
# 检查后端服务状态
curl http://localhost:3002/api/health

# 应该看到类似响应：
# {"success":true,"message":"API服务正常运行"...}
```

### 2. 打开微信开发者工具
1. 启动微信开发者工具
2. 导入项目：`/Users/kke/tcm-tongue-diagnosis/wechat-miniprogram`
3. AppID：选择"测试号"
4. 编译项目：**Cmd+B** (Mac) 或 **Ctrl+B** (Windows)

## 🔍 调试工具使用

### 内置调试面板（推荐）
1. 小程序启动后，查看右下角的绿色 🔧 按钮
2. 点击按钮打开调试面板
3. 面板功能：
   - **API状态检测** - 实时监控后端连接
   - **页面信息** - 当前页面和路由栈
   - **本地存储** - 查看和清理历史数据
   - **调试操作** - 模拟分析、查看日志
   - **快速测试** - 一键测试所有功能

### 开发者工具控制台
打开调试器面板：
1. 点击工具栏的"调试器"
2. 切换到"Console"标签
3. 运行调试脚本：
```javascript
// 复制粘贴 debug-helper.js 的内容到控制台
// 或者运行单个命令：
debugHelper.debugAll()  // 完整检查
debugHelper.testAPI()   // 测试API
```

## 🐛 常见问题排查

### 问题1：调试面板不显示
**解决方案：**
```javascript
// 在控制台运行
getCurrentPages()[0].selectComponent('debug-panel').showDebug()
```

### 问题2：API连接失败
**排查步骤：**
1. 检查后端服务：`curl http://localhost:3002/api/health`
2. 检查网络配置：调试面板 → API状态
3. 查看控制台网络请求

### 问题3：页面跳转失败
**排查步骤：**
1. 检查app.json中页面路径
2. 确认所有页面都有.json配置文件
3. 查看控制台错误信息

### 问题4：图片选择失败
**解决方案：**
1. 使用真机测试（模拟器可能不支持相机）
2. 检查权限配置
3. 查看调试面板权限状态
