## 🔍 常见问题调试

### 问题1：页面跳转失败
**症状**：点击按钮没有反应或提示"跳转失败"
**检查**：
1. 控制台是否有错误信息
2. 页面配置文件是否存在（.json文件）
3. app.json中页面路径是否正确

**解决方案**：
```bash
# 确保所有页面都有配置文件
ls pages/*//*.json
```

### 问题2：API请求失败
**症状**：分析时显示"网络请求失败"
**检查**：
1. 后端服务是否运行（端口3005）
2. 网络面板中的请求状态
3. 请求URL是否正确

**解决方案**：
```javascript
// 在app.js中检查apiBase配置
globalData: {
  apiBase: 'http://localhost:3005/api'
}
```

### 问题3：图片选择失败
**症状**：点击拍照或选择图片没有反应
**检查**：
1. 是否在真机上测试（模拟器可能不支持相机）
2. 权限配置是否正确
3. 控制台错误信息

**解决方案**：
检查 `app.json` 中的权限配置：
```json
{
  "permission": {
    "scope.camera": {
      "desc": "用于拍摄舌诊照片"
    }
  }
}
```

## 📱 模拟器 vs 真机调试

### 模拟器调试
**优点**：
- 快速开发和测试
- 完整的调试工具
- 控制台日志清晰

**限制**：
- 无法使用相机功能
- 网络环境可能不同
- 性能表现与真机有差异

### 真机调试
**优点**：
- 完整功能测试
- 真实用户体验
- 性能准确测试

**步骤**：
1. 点击"预览"按钮
2. 微信扫描二维码
3. 在手机上测试功能
